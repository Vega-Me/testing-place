# game1 — Roblox project

## Workflow rules
- Everything stays **local** (local git repo on `main`). Never push, create remotes, or publish to GitHub/Roblox unless explicitly asked.
- GitHub CLI (`gh`) is logged in as `Vega-Me` — use it only when asked to push/PR.

## Toolchain (installed via Homebrew)
- **Rojo 7.7.1** — `rojo serve` syncs `src/` into Studio live; Studio plugin is in `~/Documents/Roblox/Plugins/RojoManagedPlugin.rbxm`.
- **Lune 0.11.1** — runs `tools/*.luau` scripts.

## Project layout
- `default.project.json` — Rojo project (generated by the unpacker; services map to `src/<Service>`).
- `src/` — game content. Scripts are `.server.luau` / `.client.luau` / `.luau`; script-free subtrees are binary `.rbxm`; containers holding scripts are directories with `init.meta.json` (className/properties/attributes).
- `place.rbxl` — saved Studio place. Source of truth for Terrain and Workspace.Camera (Rojo doesn't round-trip those). Workspace/Lighting/SoundService/MaterialService use `$ignoreUnknownInstances: true`.
- `tools/unpack-place.luau` — regenerate `src/` + `default.project.json` from a place file:
  `lune run tools/unpack-place place.rbxl`  (WARNING: deletes and rewrites `src/` — commit first)

## Connected tools (MCP)
- **Roblox Studio** — Studio's built-in MCP (`/Applications/RobloxStudio.app/Contents/MacOS/StudioMCP`), registered at user scope as `Roblox_Studio`. Requires Studio → Assistant → … → Manage MCP Servers → "Enable Studio as MCP server".
- **Blender** — `blender-mcp`; Blender must be open with the MCP add-on started.
- **Figma** — claude.ai Figma connector (account seat is View on Starter plan; editing may need a Full seat).
- FigCraft (desktop app) has no MCP/API; use exported images/SVGs from it instead.
